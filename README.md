# code-du-memoire
Code utilisé et résultat obtenu dans le cadre de mon mémoire en science de l'informatique.

Ce mémoire s'impire de l'article de Wagner concernant la recherche de contre exemple dans la théorie des gaphe. (https://arxiv.org/pdf/2104.14516)

Il reprent le code template de Wagner (https://github.com/zawagner22/cross-entropy-for-combinatorics/tree/main) tout en apportant des moddification concernant sont code. 
Pour des raisons de clarté, seules les parties modifiées ou ajoutées seront documentées.
